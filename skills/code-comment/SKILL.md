# Code Comment

## 调用时机

**只要修改代码就必须调用。** 包括但不限于：新增文件、编辑现有文件、修 bug、重构、添加功能。无论改动大小，只要涉及代码变更，就同步检查并修正注释。

## 原则

注释只解释代码做什么。不引用规范、不复述代码、不堆积迭代痕迹。

## 规则

1. **只解释行为与意图**：描述函数、类型或逻辑块实际做什么。
2. **禁止引用规范**：不提及编码规范、项目约定、安全要求、分层规则、设计模式等。
3. **禁止复述代码**：不逐字翻译代码或描述语法行为。
4. **迭代同步**：代码变更时注释更新为当前行为的解释，删除过时、重复或已被替代的残留。
5. **禁止流程描述**：不在注释中解释实现流程、数据流转路径或跨层调用关系。

## 语言格式

根据仓库主语言选择注释格式：

| 语言 | 格式 |
|------|------|
| Go | GoDoc |
| JS/TS | JSDoc |
| Python | docstring |
| Java | Javadoc |
| Rust | rustdoc (`///`) |
| 其他 | 该语言社区惯例 |

导出符号必须有注释；非导出的辅助函数仅在行为不明显时添加。
