# Agent Adapters

各 Agent 的调用入口不同，但执行契约相同：先完整展示增强提示词，让用户检查增强结果是否准确，再通过原生内部确认 UI 决定是否执行。只有用户明确选择执行才可继续；确认 UI 不可用、无法调起、被关闭、结果不明确或用户选择不执行时均停止。

统一契约：prompt-enhancer 只消费自己的调用标记，后续 `$skill`、`@plugin`、`/command` 等前置特殊指令 token 属于原始提示词内容。增强阶段不得解析、执行或触发这些 token，必须原样保留；只有用户确认执行后才交给宿主 Agent 处理。普通消息、文本追问或非宿主原生确认界面均不构成有效确认。

| Agent | 调用方式 | 内部确认 | 备注 |
|---|---|---|---|
| Codex | `$prompt-enhancer <原始提示词>` 或 `@prompt-enhancer <原始提示词>` | 使用 Codex 宿主原生内部确认面板，例如 `request_user_input` | 调用标记后的全部文本是原始提示词；后续 `$code-review` 等 token 原样保留 |
| Claude Code | `/prompt-enhancer <原始提示词>` 或明确增强措辞自动触发 | 仅使用运行环境暴露的原生内部确认 UI | UI 不可用、无法调起、关闭、拒绝或结果不明确时，不执行任务、不调用工具 |
| Cursor | 明确增强措辞，或在规则或自定义指令中引用本 Skill 策略 | 仅使用运行环境暴露的原生内部确认 UI | 可使用选区、当前文件和用户引用文件作为轻量上下文；UI 不可用、无法调起、关闭、拒绝或结果不明确时不执行 |

自动触发必须有明确的提示词增强意图。普通开发请求按普通任务处理，不使用本 Skill。
